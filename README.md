# 高中英文 7000 字學習系統 V1.1

## V1.1 新增
- 深度單字卡：多義中文釋義、每字高中程度例句、常用搭配提示、字根字首、同義字、反義字、易混淆字
- 段考模式：英→中、中→英、拼字、綜合題
- 學測模式：情境克漏字、上下文選字、字義辨析
- 字庫列表可直接點進深度單字卡
- Service Worker 升級為 V1.1 cache，更新後會清理舊快取

## 內容策略
- 中文釋義：優先沿用舊制高中參考詞彙表可對應的完整釋義
- 108 課綱新增而舊字表無對應者：顯示待補充提示，不亂造中文義
- 高頻字：內建人工整理例句、搭配、字根、同反義、易混淆字
- 其他字：由詞性、字首字尾與字庫拼字相似度提供學習輔助提示；後續版本可逐步把人工內容覆蓋率提高
