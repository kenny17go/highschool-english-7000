## GitHub Pages
把此資料夾內所有檔案上傳到 GitHub repository 根目錄，並在 Settings → Pages 啟用 GitHub Pages 即可。

## 資料說明
主字庫執行時載入公開整理的 108 課綱高中英文參考詞彙資料，並用舊制字表補充中文釋義與 Level 7。部分深度內容採人工整理；未人工整理的字會由詞性、字首字尾與字庫相似度提供輔助內容，因此不應把自動生成的字根或搭配視為辭典級權威資料。

### 統計口徑
V1.3 的「真題出現紀錄」統計的是大考中心 111–115 學測英文**詞彙題四個選項**中的單字年度標記，不代表大考中心官方公布的全卷詞頻。網站另外計算的「優先度」是個人化學習指標。

## V1.4 — 101～115 學測英文全卷語料化

V1.4 新增「15 年語料庫」與自動建置管線。為避免重新散布完整試卷文字，網站只保存衍生統計：每年內容詞 token 數、不同詞形數、每字總出現次數、出現年度、逐年次數，以及詞彙題／綜合測驗／文意選填／篇章結構／閱讀／混合題等題型分布。

### 第一次上傳 GitHub 後

1. 開啟 GitHub Repository → **Actions**。
2. 選擇 **Build GSAT corpus**。
3. 按 **Run workflow**。
4. Workflow 會從大考中心官方 PDF 建置 `data/gsat-corpus-stats.json`，並自動 commit 回 repository。
5. GitHub Pages 更新後，「學測戰情室 → 15年語料庫」會顯示 15/15 已語料化與實際詞頻。

建置程式：`tools/build_gsat_corpus.py`  
Workflow：`.github/workflows/build-gsat-corpus.yml`

> ZIP 內預先放的是「來源索引版」JSON，因此即使尚未執行 Action，網站仍可正常運作；完整 15 年詞頻要在 GitHub 上第一次執行 workflow 後產生。


## V1.4.1 — 每字真題情報整合

每一個 7000 字單字詳細頁新增「101～115 學測真題情報」：

- 歷屆全卷出現總次數
- 出現年度數與完整年份標籤
- 題型分布（詞彙、綜合測驗、文意選填、篇章結構、閱讀、混合題、中譯英、作文）
- 111～115 近 5 年年度次數小圖與升／降／持平趨勢
- 真題重要度 ★1～★5
- 真題重要度會納入本機 AI 弱點優先分數，但仍和個人熟練度、錯題次數分開保存

### 真題重要度口徑

星等由「15 年出現年度數、總出現次數、近 5 年出現密度、題型廣度」計算，屬於本網站的學習排序指標，不是大考中心官方評級。完整語料尚未建置時，詳細頁會顯示「待建置」，不會以模擬數字代替。

### V1.4.1 語料建置調整

V1.4 原建置程式只輸出前 5,000 個內容詞；V1.4.1 改為保存語料中**所有實際出現的內容詞統計**，因此 7000 字庫中的低頻字只要曾出現在 101～115 全卷，也能在單字詳細頁被查到。未出現的字在完整建置後會顯示 0 次與最低 ★1。
