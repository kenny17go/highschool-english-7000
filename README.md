# 高中英文 7000 字學習系統 V1.2.1

可直接部署到 GitHub Pages 的 PWA 單字學習網站。

## V1.2.1 視覺優化

- 依 iPhone 單字學習介面重新設計：白底、深藍文字、綠色進度與標籤
- 熟悉度按鈕改為紅／黃／藍／綠四色四欄
- 單字卡改為原生 App 感卡片配置，加入學習頁收藏星號
- 全站首頁、測驗、字庫、進度與彈窗同步改為淺色教育風格
- 換用新的「高中英文 ENGLISH 7000」App Icon
- 單字完整詳細頁：中文釋義、例句、搭配、字根字首、同義字、反義字、易混淆字、學習狀態
- 收藏單字：字庫可一鍵收藏，進度頁可直接練習收藏字
- 學測優先標記：用於安排核心高價值字彙（不是歷屆精確出題次數統計）
- 字庫快速篩選：全部／收藏／學測優先／錯題
- 段考自訂範圍：可貼上老師提供的單字清單，以逗號、空格或換行分隔
- 自訂範圍即時顯示可匹配字數
- 測驗範圍新增收藏字與學測優先字
- 保留 V1.1 的段考模式／學測模式與深度單字卡
- Service Worker 更新為 V1.2，會清除舊版快取

## 既有功能
- 108 課綱 Level 1–6 + 進階補充 Level 7
- 4500 / 6000 / 7000 學習範圍切換
- 每日新字、到期複習、間隔重複
- 英文發音
- 段考模式：英中、中英、拼字、綜合
- 學測模式：情境克漏字、上下文選字
- 錯題本、學習進度、正確率、連續天數
- 學習紀錄匯出／匯入
- iPhone PWA，可加入主畫面

## GitHub Pages
把此資料夾內所有檔案上傳到 GitHub repository 根目錄，並在 Settings → Pages 啟用 GitHub Pages 即可。

## 資料說明
主字庫執行時載入公開整理的 108 課綱高中英文參考詞彙資料，並用舊制字表補充中文釋義與 Level 7。部分深度內容採人工整理；未人工整理的字會由詞性、字首字尾與字庫相似度提供輔助內容，因此不應把自動生成的字根或搭配視為辭典級權威資料。
